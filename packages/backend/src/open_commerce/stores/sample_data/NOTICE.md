# Amazon Berkeley Objects Sample

48 listings and mirrored thumbnails from Amazon Berkeley Objects (ABO).
Source: https://amazon-berkeley-objects.s3.us-east-1.amazonaws.com/index.html
Data and images: Amazon.com, CC BY 4.0. Dataset authors: Matthieu Guillaumin,
Thomas Dideriksen, Kenan Deng, Himanshu Arora, Jasmine Collins and Jitendra Malik.
See LICENSE-CC-BY-4.0.txt and manifest.json for original image URLs and hashes.

Adapted for this demo: English listing subset, truncated descriptions, synthetic
prices, inventory, popularity and ratings; image references use fixed package
identifiers and images are re-encoded on import. These are not current offers.
No Amazon customer activity or current Amazon pricing is included.

Rebuild with scripts/package_store_sample.py from the existing attributed fixture.
